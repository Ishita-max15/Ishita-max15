####  Featured Projects

🤖 **[AI-Powered Candidate Screening System](https://github.com/Ishita-max15/candidate-screening-system)**
Full-stack RAG-based technical interview platform — FastAPI backend, Next.js/TypeScript frontend. Parses a candidate's résumé, retrieves role-specific technical context from a ChromaDB vector store (Sentence Transformers embeddings), and grounds adaptive LLM-generated interview questions (easy → medium → hard) in real source material. Auto-generates a structured report with per-question scoring, strengths/weaknesses, and a Hire / Maybe / Reject recommendation, persisted in PostgreSQL. Fully containerized with Docker.

**[ReefHealth-AI — Coral Reef Health Classification](https://github.com/Ishita-max15/ReefHealth-AI)**
Ensemble deep learning system for binary classification of bleached vs. healthy coral reefs — a custom CNN with CBAM (channel + spatial) attention combined with VGG19 transfer learning, averaged via probability voting. Achieves 84% test accuracy (vs. ~80–82% for either model alone), with a full evaluation suite (ROC/AUC, confusion matrices, per-class precision/recall/F1).

 **[ParentCare](https://github.com/Ishita-max15/parentcare-app)**
Full-stack marketplace connecting families with verified caretakers for their aging parents — companionship visits, doctor escorts, and errands. Built with Next.js 15 (App Router) and Supabase (Postgres, auth, Row-Level Security); includes a family dashboard, an admin panel for managing caretakers/bookings/verifications, and booking confirmation with payment instructions.

 **[Live Voice Conversation App](https://github.com/Ishita-max15/Speech-v2)**
Real-time conversational voice interface built with FastAPI and WebSockets — streams audio between client and server, runs a conversational response engine, and converts responses back to speech (gTTS) for a live spoken back-and-forth.
